# Laba2HW
Алгоритм и блок-схема
Алгоритм
1. Начало
2. Объявить переменные и присвоить значения:

a = 10 -> стоимость газеты до 75 проданных

b = 13 -> стоимость газеты после 75 проданных

start = 75 -> количество в первый раз проданных газет 

last = 133  -> количество всех проданных газет

result -> переменная для записи результата

3. Вычислить стоимость по формуле сначала первых 75 газет и прибавить стоимость последующих:
start * a + ((last - start) * b)
4. Записать ответ в переменную result:
result = start * a + ((last - start) * b)
5. Вывести результаты расчетов с подстановкой всех значений в текст.
6. Конец
